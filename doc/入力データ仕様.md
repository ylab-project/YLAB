# YLAB公開入力データ仕様

## 対象

公開リポジトリの `data/` に含まれるモデル入力CSVと断面リストCSVの構成を説明する。記述の範囲は、配布中の `S4.csv`、`T1.csv`、`T1R.csv` が実際に使うブロックと列に限る。公開入力を作成するときは、本書の列定義とサンプルの実データに従う。

## 公開ファイル

サンプルは次の7ファイルで構成する。

| ファイル | 種別 | 参照するリストファイル |
|---|---|---|

## モデル入力CSV

### モデル情報

モデル入力CSVの先頭には、最初の `name=` 行より前に次の任意行を置ける。

| キー | 第2列 | 省略時 | 用途 |
|---|---|---|---|
| `モデル名` | モデル名 | 空文字 | 計算書の副題 |
| `説明` | 説明文 | 空文字 | 計算書の説明 |

`説明` は複数行記述できる。

```csv
モデル名,T1
説明,2層2スパンモデル
```

### ブロック構造

モデル情報行に続く本文は、カンマ区切りのブロックで構成する。各ブロックは1列目の `name=<ブロック名>` で始まり、次の `name=` 行までが同じブロックになる。

```csv
name=基本事項
地下階数,0
PH階数,0

name=構造計算条件
構造階高の自動計算,Y
```

読込時には次の行をデータとして扱わない。

- 空行
- カンマだけで構成された行
- 先頭の有効文字が `%` のコメント行（列見出しや単位の記載に使える）

ブロック名はYLABに登録された名称と一致させる。たとえば最適化の設定ブロックは `name=最適化条件` であり、`name=最適化計算条件` ではない。登録されていないブロック名を書くと読込が停止する。同じブロック名を複数回記述した場合は、各ブロックのデータ行をファイル内の順に連結して読み込む。

どのモデルもすべてのブロックを必要とするわけではない。必要なブロックは、目的に近いサンプルを基準にする。

### 行の記述形式

ブロックの行には2つの形式がある。

**キー形式**は1列目に項目名、2列目以降にその値を置く。行の順序は結果に影響しない。計算条件のブロックがこの形式をとる。

**列形式**は列位置に意味があり、1行が1つの対象（部材、節点、荷重など）を表す。架構、断面、部材配置、荷重のブロックがこの形式をとる。

### 省略の扱い

「省略時」の意味は行の形式によって異なる。

- キー形式では、該当するキーの行自体を書かない場合を指す。行を残して値だけを空欄にしても、既定値になるとは限らない。Y/Nを受け取るキーには `Y` または `N` を明記する。
- 列形式では、該当するセルを空欄にする場合を指す。途中の任意列を使わない場合は、後続列の位置がずれないように空欄セルを残す。

空欄と0の意味は同じではない。

### 名前の参照規則

別のブロックで定義した名前を参照する値は、参照先の表記と一致させる。英字の大文字・小文字、全角・半角、空白も名前の一部として扱う。

| 参照元 | 参照する値 | 参照先 |
|---|---|---|
| `階` | 層名 | `層` の層名 |
| `S梁断面`、`大梁配置` | 層名 | `層` の層名 |
| `S柱断面`、`柱配置` | 階名 | `階` の階名 |
| スパン、節点、支点、部材配置、荷重 | X軸、Y軸 | `軸X`、`軸Y` の軸名 |
| `断面リスト` | 材料名 | `材料` の材料名 |
| `S梁断面`、`S柱断面` | 断面リスト名 | `断面リスト` の断面リスト名 |
| `大梁配置`、`柱配置` | 断面符号 | `S梁断面`、`S柱断面` の符号 |
| `節点荷重`、`追加節点荷重`、`梁要素荷重` | 荷重ケース名 | `荷重ケース` の荷重ケース名 |

## 計算条件

### 基本事項

| キー | 値 | 省略時 |
|---|---|---|
| `地下階数` | 地下階数 | ― |
| `PH階数` | ペントハウス階数 | ― |

### 構造計算条件

論理値は `Y` または `N` で指定する。第3列以降を空欄にした場合は、省略時の欄に示した値を使う。

| キー | 第2列 | 第3列以降 | 省略時 |
|---|---|---|---|
| `構造階高の自動計算` | Y/N | ― | Y |
| `自重の自動計算` | Y/N | 梁割増係数、柱割増係数 | Y、係数とも1 |
| `仕上荷重の考慮` | Y/N | ― | Y |
| `仕上S柱`、`仕上S梁`、`仕上RC梁` | 重量 (N/mm2) | ― | `5e-4` |
| `柱・梁せん断変形の考慮` | Y/N | ― | Y |
| `支点浮き上がりの考慮` | Y/N | ― | N |
| `床によるS梁剛性の考慮` | 0/1/2 | 2のとき片側増大率、両側増大率 | 1、増大率は1.3と1.5 |
| `床によるRC梁剛性の考慮` | 0/1/2 | 同上 | 同上 |
| `床による梁剛性の考慮` | 0/1/2 | 同上 | 同上 |
| `ブレースの取り付き位置` | 1/2 | ― | 1 |
| `曲げの設計におけるウェブの考慮（梁中央部）` | Y/N | ― | N |
| `曲げの設計におけるウェブの考慮（梁端部）` | Y/N | ― | N |
| `スカラップの考慮` | Y/N | スカラップ長 | Y、長さ35 |
| `横座屈の考慮` | Y/N | ― | Y |
| `柱座屈長さ係数の自動計算` | Y/N | ― | Y |
| `梁・柱面での断面算定` | Y/N | ― | Y |
| `SN材H形鋼の幅厚比制限値の考慮` | Y/N | ― | Y |
| `保有耐力横補剛の事前処理` | Y/N | ― | Y |
| `保有耐力接合（仕口）の事前処理` | Y/N | ― | Y |

床剛性の選択肢は、0が考慮しない、1が協力幅による、2が増大率の直接入力である。2を選んだときだけ第3列と第4列を読む。`床による梁剛性の考慮` はS梁とRC梁の両方へ同じ値を設定する。

ブレースの取り付き位置は、1が基礎梁の天端位置、2が基礎梁の梁心位置である。

### 最適化条件

| キー | 第2列 | 第3列 | 省略時 |
|---|---|---|---|
| `iter_set` | 開始番号 | 終了番号 | 1から1 |
| `do_parallel` | Y/N | ― | Y |
| `maxiter_in_LS` | 繰返し数 | ― | 400 |
| `display` | None/Iter/Iter10 | ― | Iter10 |

`iter_set` は試行番号の範囲を指定する。開始番号1は変数の初期値を用いる試行を指す。

### 制約条件

各行は条件名、考慮の有無、余裕率αの3列で指定する。αを空欄にすると既定値を使う。

| 条件名 | 第3列の値 | 第2列の既定 | 第3列の既定 |
|---|---|---|---|
| `許容応力度比` | α | Y | 0.05 |
| `層間変形角` | α | Y | 0.05 |
| `梁たわみ` | α | Y | 0 |
| `幅厚比` | α | Y | 0 |
| `保有耐力横補剛` | α | Y | 0 |
| `保有耐力接合（仕口）` | α | Y | 0 |
| `柱梁耐力比` | α | Y | 0 |
| `梁段差` | 必要段差 (mm) | Y | 0 |
| `梁段差実寸` | 必要段差 (mm) | N | 0 |
| `柱外径上下階` | α | Y | 0 |
| `梁せい分布平滑化` | 指定しない | N | ― |
| `柱部材種別` | ― | FB | ― |
| `梁部材種別` | ― | FA | ― |

`細長比` は `保有耐力横補剛` の別名であり、同じ制約を指す。`梁段差` と `梁段差実寸` は必要段差を共有する。`梁せい分布平滑化` の第3列は廃止されており、値を書くと読込が停止する。部材種別は `FA`、`FB`、`FC`、`FD` から選ぶ。

### 出力制御

1列目に `梁断面リスト` または `柱断面リスト`、2列目以降に出力する断面符号を並べる。空欄が現れた位置で打ち切る。

```csv
name=出力制御
%,1,2,3,4,5,6
梁断面リスト,GX1,GX2,GX3,GY1,GY2,GY3
柱断面リスト,C1,C2,C3,C4
```

## 断面と設計変数

### 材料

| 列 | 項目 | 省略時 |
|---:|---|---|
| 1 | 材料名 | ― |
| 2 | ヤング係数E (N/mm2) | ― |
| 3 | ポアソン比 | ― |
| 4 | 基準強度F (N/mm2) | ― |

材料名の先頭2文字で鋼種を判別する。`SN` で始まる材料はSN材として扱い、`SN材H形鋼の幅厚比制限値の考慮` の対象になる。せん断弾性係数はポアソン比0.3のとき79400を用い、それ以外はEとポアソン比から求める。

### 断面リスト

`断面リスト` ブロックは、モデル内で使用する断面候補と外部リストCSVを対応付ける。

```csv
name=断面リスト
%断面リスト名,鉄骨形状,材料名,リストファイル名,コスト係数,コスト定数,フェーズ番号,type
%,,,,(省略可),(省略可),(省略可),(省略可)
LC,□,BCR295,Box_list.csv,195,0,1,BCR
LC,□,BCP325,Box_list.csv,245,0,1,BCP
LG,H,SN490B,H_SN_list.csv,150,0,1,細幅
```

| 列 | 項目 | 必須 | 省略時 |
|---:|---|---|---|
| 1 | 断面リスト名 | 必須 | ― |
| 2 | 鉄骨形状 | 必須 | ― |
| 3 | 材料名 | 必須 | ― |
| 4 | リストファイル名 | 必須 | ― |
| 5 | コスト係数 | 任意 | `1` |
| 6 | コスト定数 | 任意 | `0` |
| 7 | フェーズ番号 | 任意 | `1` |
| 8 | `type` の絞り込み値 | 任意 | 絞り込みなし |

同じ断面リスト名を複数行に記述すると、各行の候補を1つのリストとして合成する。上の例では `LC` に `Box_list.csv` の `BCR` と `BCP` を別の材料とコスト係数で割り当てている。同じ断面リスト名に指定する鉄骨形状は統一する。

列の指定には次の規則がある。

- 材料を割り当てない行では、材料名に `-` を指定できる。
- 任意列を指定しない場合は、列位置が分かるように対応するセルを空欄で残す。
- リストファイル名はモデル入力ファイルの所在ディレクトリを基準に解決する。たとえば `data/S4.csv` の `Box_list.csv` は `data/Box_list.csv` を指す。

任意列を使わない例を示す。

```csv
name=断面リスト,,,,,,,,,,,,,,,,,
%断面リスト名,鉄骨形状,材料名,リストファイル名,コスト係数,コスト定数,フェーズ番号,type,,,,,,,,,,
%,,,,(省略可),(省略可),(省略可),(省略可),,,,,,,,,,
HG,H,SN400,JIS_chu_hoso_list.csv,,,,,,,,,,,,,,
BC,□,BCR295,BCR_list.csv,,,,,,,,,,,,,,
```

### S梁断面・S柱断面

S梁断面は層ごと、S柱断面は階ごとに、符号と断面リストと設計変数名を対応付ける。

| 列 | S梁断面 | S柱断面 | 省略時 |
|---:|---|---|---|
| 1 | 層名 | 階名 | ― |
| 2 | 符号 | 符号 | ― |
| 3 | 添字 | 添字 | ― |
| 4 | 断面リスト名 | 断面リスト名 | ― |
| 5〜 | 変数名 | 変数名 | ― |
| 9 | 部材種別 | 部材種別 | 制約条件の既定 |

変数名の個数は鉄骨形状で決まる。H形鋼はH、B、tw、tfの4つを第5列から第8列に置き、角形鋼管はD、tの2つを第5列と第6列に置く。部材種別は形状によらず第9列に書き、`FA`、`FB`、`FC`、`FD` から選ぶ。空欄のときは制約条件の `梁部材種別` または `柱部材種別` を使う。

サンプルのS柱断面はコメント見出しで部材種別を第7列に示しているが、これは旧形式である。第7列の指定も互換入力として読み込まれるが、新しい入力では第9列を使用する。

ここに書いた変数名が設計変数ブロックに無い場合は、変数として自動で追加される。

### S梁断面(仮定)・S柱断面(仮定)

| 列 | 項目 | 省略時 |
|---:|---|---|
| 1 | 層名（S柱断面(仮定)は階名） | ― |
| 2 | 符号 | ― |
| 3 | 添字 | ― |
| 4 | 鉄骨登録形状 | ― |

読み込むのは第4列までである。サンプルは第5列以降にタイプ名や中央・右端の形状を並べているが、これらは読み込まれない。

### 設計変数

| 列 | 項目 | 省略時 |
|---:|---|---|
| 1 | 変数名 | ― |
| 2 | 変数 (T) / 固定 (F) | T |
| 3 | 値 | 0 |

読み込むのは第3列までである。サンプルの見出しにある下限値と上限値は読み込まれない。`T1.csv` のコメント見出しは第2列を初期値、第3列を変数としているが、現在の列順序は第2列が変数または固定、第3列が値である。

## 荷重

### 荷重ケース

| 列 | 項目 | 省略時 |
|---:|---|---|
| 1 | 荷重ケース名 | ― |

### 節点荷重・追加節点荷重

| 列 | 項目 | 省略時 |
|---:|---|---|
| 1 | 荷重ケース名 | 直前の行と同じ |
| 2 | 層名 | ― |
| 3 | X軸 | ― |
| 4 | Y軸 | ― |
| 5-7 | Fx、Fy、Fz (N) | 0 |
| 8-10 | Mx、My、Mz (N.mm) | 0 |

同じ節点に複数行を書くと、荷重は加算される。

### 梁要素荷重

| 列 | 項目 | 省略時 |
|---:|---|---|
| 1 | 荷重ケース名 | ― |
| 2 | 層名 | ― |
| 3 | フレーム | ― |
| 4 | 軸（始端） | ― |
| 5 | 軸（終端） | ― |
| 6-11 | i端の Fx、Fy、Fz、Mx、My、Mz | ― |
| 12-17 | j端の Fx、Fy、Fz、Mx、My、Mz | ― |
| 18 | M0 (N.mm) | ― |
| 19 | 継続 (T/F) | F |

力の単位はN、モーメントの単位はN.mmである。第19列に `T` を書くと次の行を同じ梁の2本目の分割梁として読み、その行の第1列から第5列は空欄にする。

## 断面リストCSV

### 命名

公開する断面リストのファイル名は `_list.csv` で終える。旧名の `union_` 接頭辞は付けない。

```text
<用途または規格名>_list.csv
```

モデル入力の `断面リスト` ブロックには、このファイル名を大文字・小文字を含めて正確に記述する。

### 列構成

断面リストはヘッダー行を持つカンマ区切りCSVとする。`label` と `type` は読込処理が参照する列であり、省略しない。寸法列は鉄骨形状に応じて異なる。

| ファイル | ヘッダー |
|---|---|
| `Box_list.csv` | `label,type,symbol,D,t,r` |
| `BCR_list.csv` | `label,type,symbol,D,t,r` |
| `H_SN_list.csv` | `label,type,symbol,H,B,tw,tf,r` |
| `JIS_chu_hoso_list.csv` | `label,type,symbol,H,B,tw,tf,r` |

角形鋼管の例を示す。

```csv
label,type,symbol,D,t,r
冷間ロール成形角形鋼管,BCR,□,150,6,15
```

H形鋼の例は次のとおりである。

```csv
label,type,symbol,H,B,tw,tf,r
JIS,細幅,H,100,50,5,7,8
```

リストCSVでも、先頭が `%` の行はコメントとして扱い、空行とカンマだけの行は読み飛ばす。モデル入力の `断面リスト` ブロックで8列目の `type` を指定した場合は、このヘッダーの `type` 列を完全一致で絞り込む。

## 文字コードと改行

公開ファイルは7つともCP932、BOMなし、CRLFである。新しい公開入力CSVも同じ形式で作成し、編集時はファイルの文字コードと改行を変えない。

## 値の書き方

- 数値には小数表記とE記法を使用できる。
- 論理値は大文字の `Y` / `N` または `T` / `F` で指定する。
- 単位はブロックごとに異なるため、サンプル内のコメントを確認する。
